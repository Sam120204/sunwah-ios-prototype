\section{模块说明}
Login /\allowbreak{} Register 模块覆盖未登录用户的两个可用认证路径：注册新账号并完成 email verification，以及使用已有 account/\allowbreak{}email 与 password 登录。当前源材料将两条路径录在同一支视频中，因此本模块保留为一个 User Story。
\begin{quote}\small 范围说明：\texttt{Google}、\texttt{Microsoft} 和 \texttt{Sign in with Apple} 虽然显示在 \texttt{Login} 页面，但不属于本次验收范围。当前验收路径仅包括 \texttt{Register New Account} 和标准 email/\allowbreak{}password \texttt{Sign In}。\end{quote}

\section{User Story 1 - 注册新账号并使用已有账号登录}
\textbf{Story ID:} \texttt{US-AUTH-01}
\textbf{用户故事：} 作为未登录用户，我希望注册新账号并验证 email，或使用已有 account/\allowbreak{}email 和 password 登录，从而进入应用的 \texttt{Markets} 页面。
\textbf{Video:} \href{https://jjpvro70sief.jp.larksuite.com/wiki/CDmcwSmsNinDn8kb92Nj980Epne}{US-AUTH-01 验收视频}
\subsection{Walkthrough}
\subsubsection{A. \texttt{Login} 页面与范围说明}
\begin{enumerate}
\item 打开应用并停留在 \texttt{Login} 页面。
\item 展示 account/\allowbreak{}email 与 password 输入框。输入 password 后操作 eye icon，确认 password 可显示和隐藏。
\item 在任一必填字段为空时展示 \texttt{Sign In} 不可用；两个字段均填写后展示 \texttt{Sign In} 可用。
\item 简短展示 \texttt{Google}、\texttt{Microsoft}、\texttt{Sign in with Apple}，说明它们不属于当前验收路径。
\end{enumerate}

\subsubsection{B. 注册新账号并验证 email}
\begin{enumerate}
\setcounter{enumi}{4}
\item 点击 \texttt{Register New Account}，进入 \texttt{Create Account}。
\item 依次输入 display name、email 和 password。先用少于 8 个字符的 password 展示按钮不可用，再补足为有效 password。
\item 点击 \texttt{Create Account}。确认应用创建 pending registration、向 email 发送六位 verification code，并进入 \texttt{Verify Email}。
\item 在 code 未满六位时展示 \texttt{Verify and Continue} 不可用；输入完整六位 code 后按钮可用。
\item 点击 \texttt{Verify and Continue}。验证成功后，确认账号创建完成、用户自动登录，并进入 \texttt{Markets}。
\end{enumerate}

\subsubsection{C. 已有账号登录}
\begin{enumerate}
\setcounter{enumi}{9}
\item 退出或重置到 \texttt{Login} 页面。
\item 输入已有 account/\allowbreak{}email 和 password；两个字段都有效后点击 \texttt{Sign In}。
\item 展示 signing-in state；认证成功后再次确认默认进入 \texttt{Markets}。
\end{enumerate}
