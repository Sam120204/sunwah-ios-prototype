\section{模組說明}
\texttt{Admin Portal} 是客戶端應用背後的運營控制台。本模組的核心不是只瀏覽後台頁面，而是證明後台與移動端使用同一組後端資源：管理員對 \texttt{ETF Catalogue} 和 \texttt{Model Portfolios} 的變更，在刷新移動端後可以得到驗證；同時管理員可通過 \texttt{Dashboard}、\texttt{Users} 和 \texttt{User Portfolios} 監控平台狀態。

\section{User Story 1 - 通過 \texttt{Admin Portal} 維護並核驗客戶端內容}
\textbf{Story ID:} \texttt{US-ADM-01}
\textbf{用戶故事：} 作為管理員，我希望維護 ETF 目錄和 Model Portfolio templates，並在移動端驗證變更，同時從統一後台查看用戶和 portfolio 運營信息。
\subsection{Walkthrough}
\subsubsection{A. 查看 \texttt{Dashboard}}
\begin{enumerate}
\item 登入 \texttt{Admin Portal} 並打開 \texttt{Dashboard}。
\item 展示 total users、ETF catalogue size、user portfolios、structured notes 和 ETF tier distribution 等概覽資料，說明這些資源來自與移動端共享的後端。
\end{enumerate}

\screenshotDescSingle{\textbf{ADM-US1-01} \textemdash{} \texttt{Dashboard} 完整概覽，包含主要 counters、ETF tier distribution 和最近活動。}
\subsubsection{B. 添加 ETF，並在移動端驗證}
\begin{enumerate}
\setcounter{enumi}{2}
\item 先在 iOS simulator 搜尋一只當前不存在或未啟用的測試 ETF，記錄找不到該 ETF 的基線狀態。
\item 切換到 \texttt{Admin Portal \textgreater{} ETF Catalogue}。展示按 symbol/\allowbreak{}name/\allowbreak{}issuer 搜尋，以及按 tier 或 asset class 篩選。
\item 展示 catalogue 中的 exchange、currency、asset class、region、sector、issuer、expense ratio 等字段。
\item 使用 \texttt{Add by Ticker} 或 \texttt{Add ETF manually} 添加測試 ETF。若采用手動流程，填寫 symbol、name、exchange、currency、asset class、region、sector、issuer、inception date、expense ratio 和 tier。
\item 返回 simulator，刷新 ETF search/\allowbreak{}list，確認相同 ETF 已出現。
\end{enumerate}

\subsubsection{C. 停用 ETF，並在移動端驗證}
\begin{enumerate}
\setcounter{enumi}{7}
\item 在 \texttt{ETF Catalogue} 選擇一只當前可在移動端搜尋到的測試 ETF，將其設為 inactive/\allowbreak{}deactivated。
\item 返回 simulator，刷新 ETF search/\allowbreak{}list，確認該 ETF 不再作為 active product 出現。
\end{enumerate}
\subsubsection{D. 修改 \texttt{Model Portfolios}，並在移動端驗證}
\begin{enumerate}
\setcounter{enumi}{9}
\item 先在 simulator 打開一個已發布的 Model Portfolio，記錄其 title、display order、risk band、summary 和 ETF allocations 基線。
\item 切換到 \texttt{Admin Portal \textgreater{} Model Portfolios}。展示 template key、display order、title、risk band、return range、horizon、summary、reference note、status 和 ETF allocations。
\item 編輯一個容易識別且適合演示的字段，例如 title、display order、risk band、summary 或 allocation。若修改 allocation，確認總權重為 100\%。保存並保持 template 為 \texttt{published}。
\item 返回 simulator，刷新或重新打開 Model Portfolio 頁面，確認客戶端顯示最新配置。
\item 可選補充發布邊界：將专用測試 template 改為 \texttt{draft} 或 \texttt{hidden}，刷新客戶端確認不再出現；再恢複測試資料，避免影響後續演示。
\end{enumerate}

\subsubsection{E. 查看運營頁面}
\begin{enumerate}
\setcounter{enumi}{14}
\item 打開 \texttt{Users}，展示 search、role/\allowbreak{}status filters，以及 verification status、account status、risk profile、last login、created date。使用測試用戶或對 PII 打碼。
\item 打開 \texttt{User Portfolios}，展示 owner、base currency、objective、horizon、holdings count 和 created time。
\end{enumerate}
