\section{模組說明}
Login /\allowbreak{} Register 模組覆蓋未登入用戶的兩個可用認證路徑：註冊新賬號並完成 email verification，以及使用已有 account/\allowbreak{}email 與 password 登入。當前源材料將兩條路徑錄在同一支視頻中，因此本模組保留為一個 User Story。
\begin{quote}\small 範圍說明：\texttt{Google}、\texttt{Microsoft} 和 \texttt{Sign in with Apple} 雖然顯示在 \texttt{Login} 頁面，但不屬於本次驗收範圍。當前驗收路徑僅包括 \texttt{Register New Account} 和標準 email/\allowbreak{}password \texttt{Sign In}。\end{quote}

\section{User Story 1 - 註冊新賬號並使用已有賬號登入}
\textbf{Story ID:} \texttt{US-AUTH-01}
\textbf{用戶故事：} 作為未登入用戶，我希望註冊新賬號並驗證 email，或使用已有 account/\allowbreak{}email 和 password 登入，從而進入應用的 \texttt{Markets} 頁面。
\subsection{Walkthrough}
\subsubsection{A. \texttt{Login} 頁面與範圍說明}
\begin{enumerate}
\item 打開應用並停留在 \texttt{Login} 頁面。
\item 展示 account/\allowbreak{}email 與 password 輸入框。輸入 password 後操作 eye icon，確認 password 可顯示和隱藏。
\item 在任一必填字段為空時展示 \texttt{Sign In} 不可用；兩個字段均填寫後展示 \texttt{Sign In} 可用。
\item 簡短展示 \texttt{Google}、\texttt{Microsoft}、\texttt{Sign in with Apple}，說明它們不屬於當前驗收路徑。
\end{enumerate}

\subsubsection{B. 註冊新賬號並驗證 email}
\begin{enumerate}
\setcounter{enumi}{4}
\item 點擊 \texttt{Register New Account}，進入 \texttt{Create Account}。
\item 依次輸入 display name、email 和 password。先用少於 8 個字符的 password 展示按鈕不可用，再補足為有效 password。
\item 點擊 \texttt{Create Account}。確認應用創建 pending registration、向 email 發送六位 verification code，並進入 \texttt{Verify Email}。
\item 在 code 未滿六位時展示 \texttt{Verify and Continue} 不可用；輸入完整六位 code 後按鈕可用。
\item 點擊 \texttt{Verify and Continue}。驗證成功後，確認賬號創建完成、用戶自動登入，並進入 \texttt{Markets}。
\end{enumerate}

\subsubsection{C. 已有賬號登入}
\begin{enumerate}
\setcounter{enumi}{9}
\item 退出或重置到 \texttt{Login} 頁面。
\item 輸入已有 account/\allowbreak{}email 和 password；兩個字段都有效後點擊 \texttt{Sign In}。
\item 展示 signing-in state；認證成功後再次確認默認進入 \texttt{Markets}。
\end{enumerate}
