\section{Module Overview}
The Login /\allowbreak{} Register module covers the two available authentication paths for non-logged-in users: registering a new account and completing email verification, and logging in using an existing account/\allowbreak{}email and password. The current source material records the two paths in the same video, so this module remains as a User Story.
\begin{quote}\small Scope: Although \texttt{Google}, \texttt{Microsoft} and \texttt{Sign in with Apple} are displayed on the \texttt{Login} page, they are outside this acceptance scope. The accepted paths are \texttt{Register New Account} and standard email/\allowbreak{}password \texttt{Sign In}.\end{quote}

\section{User Story 1 - Register a new account and log in using an existing account}
\textbf{Story ID:} \texttt{US-AUTH-01}
\textbf{User story:} As an unauthenticated user, I want to register a new account and verify my email, or sign in with an existing account/\allowbreak{}email and password, so that I can enter the application's \texttt{Markets} page.
\textbf{Video:} \href{https://jjpvro70sief.jp.larksuite.com/wiki/CDmcwSmsNinDn8kb92Nj980Epne}{US-AUTH-01 Acceptance Video}
\subsection{Walkthrough}
\subsubsection{A. \texttt{Login} page and scope description}
\begin{enumerate}
\item Open the application and stay on the \texttt{Login} page.
\item Display the account/\allowbreak{}email and password fields. After entering the password, tap the eye icon and confirm that the password can be shown and hidden.
\item Confirm that \texttt{Sign In} is disabled when either required field is empty and enabled after both fields are completed.
\item Briefly display \texttt{Google}, \texttt{Microsoft}, and \texttt{Sign in with Apple} to explain that they do not belong to the current acceptance path.
\end{enumerate}

\subsubsection{B. Register a new account and verify email}
\begin{enumerate}
\setcounter{enumi}{4}
\item Click \texttt{Register New Account} to enter \texttt{Create Account}.
\item Enter display name, email and password. First use a password shorter than 8 characters to show the disabled state, then enter a valid password.
\item Click \texttt{Create Account}. Confirm that the application creates a pending registration, sends a six-digit verification code by email, and opens \texttt{Verify Email}.
\item Confirm that \texttt{Verify and Continue} is disabled when the code has fewer than six digits and enabled after a complete six-digit code is entered.
\item Click \texttt{Verify and Continue}. After successful verification, confirm that the account creation is completed, the user automatically logs in, and enters \texttt{Markets}.
\end{enumerate}

\subsubsection{C. Sign in with an existing account}
\begin{enumerate}
\setcounter{enumi}{9}
\item Exit or reset to the \texttt{Login} page.
\item Enter the existing account/\allowbreak{}email and password; click \texttt{Sign In} after both fields are valid.
\item Display signing-in state; after successful authentication, confirm again and enter \texttt{Markets} by default.
\end{enumerate}
