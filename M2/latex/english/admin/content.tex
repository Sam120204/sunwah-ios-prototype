\section{Module Overview}
\texttt{Admin Portal} is the operations console behind the client application. This module proves that the portal and mobile app use the same backend resources: changes to \texttt{ETF Catalogue} and \texttt{Model Portfolios} can be verified after refreshing the mobile app, while administrators can monitor platform status through \texttt{Dashboard}, \texttt{Users} and \texttt{User Portfolios}.

\section{User Story 1 - Maintain and verify client content through \texttt{Admin Portal}}
\textbf{Story ID:} \texttt{US-ADM-01}
\textbf{User story:} As an administrator, I want to maintain the ETF catalog and Model Portfolio templates and validate changes on mobile while viewing user and portfolio operational information from a unified backend.
\subsection{Walkthrough}
\subsubsection{A. View \texttt{Dashboard}}
\begin{enumerate}
\item Log in to the \texttt{Admin Portal} and open the \texttt{Dashboard}.
\item Display overview data such as total users, ETF catalogue size, user portfolios, structured notes, and ETF tier distribution, indicating that these resources come from the backend shared with the mobile app.
\end{enumerate}

\screenshotDescSingle{\textbf{ADM-US1-01} \textemdash{} \texttt{Dashboard} A complete overview of major counters, ETF tier distributions and recent activity.}
\subsubsection{B. Add an ETF and verify it in the mobile app}
\begin{enumerate}
\setcounter{enumi}{2}
\item First search for a test ETF that does not currently exist or is not enabled in the iOS simulator, and record the baseline status of the ETF that cannot be found.
\item Switch to \texttt{Admin Portal \textgreater{} ETF Catalogue}. Show search by symbol/\allowbreak{}name/\allowbreak{}issuer and filters for tier and asset class.
\item Display the exchange, currency, asset class, region, sector, issuer, expense ratio and other fields in the catalog.
\item Add a test ETF using \texttt{Add by Ticker} or \texttt{Add ETF manually}. If using manual process, fill in symbol, name, exchange, currency, asset class, region, sector, issuer, inception date, expense ratio and tier.
\item Return to the simulator, refresh the ETF search/\allowbreak{}list, and confirm that the same ETF appears.
\end{enumerate}

\subsubsection{C. Deactivate an ETF and verify it in the mobile app}
\begin{enumerate}
\setcounter{enumi}{7}
\item In \texttt{ETF Catalogue}, select a test ETF that is currently searchable in the mobile app and set it to inactive/\allowbreak{}deactivated.
\item Return to the simulator, refresh the ETF search/\allowbreak{}list, and confirm that the ETF no longer appears as an active product.
\end{enumerate}
\subsubsection{D. Modify \texttt{Model Portfolios} and verify the change in the mobile app}
\begin{enumerate}
\setcounter{enumi}{9}
\item First open a published Model Portfolio in the simulator and record its title, display order, risk band, summary and ETF allocations baseline.
\item Switch to \texttt{Admin Portal \textgreater{} Model Portfolios}. Display template key, display order, title, risk band, return range, horizon, summary, reference note, status and ETF allocations.
\item Edit a field that is easily identifiable and appropriate for the presentation, such as title, display order, risk band, summary, or allocation. If you modify allocation, confirm that the total weight is 100\%. Save and keep the template as \texttt{published}.
\item Return to the simulator, refresh or reopen the Model Portfolio page, and confirm that the client displays the latest configuration.
\item Optional supplementary release boundary: change the dedicated test template to \texttt{draft} or \texttt{hidden}, refresh the client to confirm that it no longer appears; then restore the test data to avoid affecting subsequent demonstrations.
\end{enumerate}

\subsubsection{E. View the operations pages}
\begin{enumerate}
\setcounter{enumi}{14}
\item Open \texttt{Users} to display search, role/\allowbreak{}status filters, verification status, account status, risk profile, last login, and created date. Use test users or redact PII.
\item Open \texttt{User Portfolios} and display owner, base currency, objective, horizon, holdings count and created time.
\end{enumerate}
